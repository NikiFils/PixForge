# PixForge

> Универсальный конвертер изображений и PSD для Windows.
> Пакетная обработка с пошаговым превью, фильтрами и отчётами.

## Возможности

- **Входные форматы:** PSD, PSB, TIFF, TGA, BMP, WebP, GIF, ICO, PNG, JPEG, PDF, AI, HEIC/HEIF
- **Выходные форматы:** PNG (прозрачный / белый), JPG, WEBP, TIFF, BMP, PDF, AVIF
- **Пакетная обработка** — папки сканируются рекурсивно, включая все подпапки
- **Пошаговое превью** — каждый файл показывается, вы решаете: сохранить или пропустить
- **Фильтры:**
  - по артикулам (полное или частичное совпадение с именем файла)
  - по папкам (маски `Render`, `PSD*`, `*backup*`)
  - по дате изменения / создания (сутки / неделя / месяц / год / свой период)
- **Импорт артикулов:**
  - TXT, CSV, XLSX, XLSM, DOCX
  - Google Sheets (публичная таблица или Service Account)
- **Автоматические отчёты** по завершении (TXT со всеми деталями)
- **Тёмная / светлая / системная тема**
- **Адаптивный интерфейс** — от 640 px до 4K, панель можно перетаскивать мышью
- **Всплывающие подсказки** — включаются / выключаются в настройках

## Требования

- **Windows** 10 или 11 (64-bit)
- **Python** 3.10 или выше
- **Интернет** — только для установки зависимостей и работы с Google Sheets

## Установка

Склонируй репозиторий и запусти:

```powershell
git clone https://github.com/NikiFils/PixForge.git
cd PixForge
pip install -r requirements.txt
python PixForge.pyw
```

При первом запуске приложение само предложит доустановить недостающие библиотеки.

Альтернатива — скачать `PixForge.pyw` и `requirements.txt` вручную, положить в одну папку, затем:

```powershell
pip install -r requirements.txt
python PixForge.pyw
```

## Использование

1. **Выберите папку** с исходниками (кнопка «Выбрать папку» или вставьте путь вручную).
2. **Настройте форматы**: входные расширения (пресет или вручную), выходные форматы.
3. **Задайте фильтры** (опционально):
   - артикулы — вставьте списком, загрузите из файла или из Google Sheets;
   - папки — какие включать, какие игнорировать;
   - дата — за какой период искать.
4. **Нажмите СТАРТ (F5)** — начнётся обработка.
5. Для каждого файла: **Y / →** сохранить, **N / ←** пропустить, **A** сохранить все оставшиеся.
6. **Esc** — завершить и посмотреть итоги.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F5` | Старт обработки |
| `Y` / `→` | Сохранить текущий файл |
| `N` / `←` | Пропустить текущий файл |
| `A` | Сохранить все оставшиеся |
| `Esc` | Завершить и показать итоги |

## Настройки

Файл настроек хранится в:

```
%USERPROFILE%\.pixforge_settings.json
```

Логи ошибок и pip-логов — рядом со скриптом:

```
pixforge_error.log
pixforge_pip.log
```

## Зависимости

| Пакет | Назначение |
|---|---|
| **flet** | UI-фреймворк |
| **Pillow** | Работа с растровыми изображениями |
| **psd-tools** | Чтение PSD / PSB |
| **openpyxl** | Импорт артикулов из Excel |
| **gspread + google-auth** | Google Sheets |
| **PyMuPDF** | PDF и AI |
| **pillow-heif** | HEIC / HEIF |
| **pillow-avif-plugin** | AVIF |

Все зависимости перечислены в [requirements.txt](requirements.txt).
